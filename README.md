# اليوم العالمي للطفل — صوت الطفولة

مشروع مدرسي تفاعلي ببايثون وStreamlit، يتضمن حقوق الطفل، نموذج مشاركة مجهولًا، وجدار رسائل لا يعرض إلا المشاركات التي توافق عليها المعلمة.

## التشغيل محليًا

```bash
python -m pip install -r requirements.txt
TEACHER_PASSWORD='ضعوا-كلمة-مرور-قوية' streamlit run app.py
```

افتحوا الرابط المحلي الذي يظهر في الطرفية. تُحفظ الرسائل في `messages.db` على الجهاز الذي يشغّل التطبيق.

## تشغيله على استضافة مشتركة

ارفعوا هذا المجلد إلى مستودع GitHub، ثم اربطوا المستودع بخدمة تستضيف تطبيقات Streamlit. في إعدادات الخدمة:

1. أضيفوا السر `TEACHER_PASSWORD` واختروا كلمة مرور قوية لا تُكتب في ملفات GitHub.
2. اجعلوا `MESSAGES_DB` يشير إلى ملف داخل مساحة تخزين دائمة، مثل `/mount/data/messages.db`، واربطوا مجلد `/mount/data` بقرص دائم.
3. لا تنشروا ملف قاعدة البيانات أو كلمة المرور في المستودع.

بدون مساحة تخزين دائمة قد تُمحى الرسائل عند إعادة تشغيل الخدمة. قاعدة SQLite مناسبة لمشروع مدرسي بسيط على نسخة تطبيق واحدة؛ عند التوسع لعدة نسخ، استبدلوها بقاعدة بيانات مُدارة مشتركة.

## الخصوصية

النموذج لا يطلب أسماء أو أرقامًا أو بيانات اتصال. تظل الرسالة مخفية إلى أن توافق عليها المعلمة. ينبغي تنبيه الطالبات إلى عدم كتابة بيانات شخصية داخل نص الرسالة.
