# اليوم العالمي للطفل — صوت الطفولة

مشروع مدرسي تفاعلي ببايثون وStreamlit، يتضمن حقوق الطفل، نموذج مشاركة مجهولًا، وجدار رسائل لا يعرض إلا المشاركات التي توافق عليها المعلمة.

## التشغيل محليًا

```bash
python -m pip install -r requirements.txt
TEACHER_PASSWORD='ضعوا-كلمة-مرور-قوية' streamlit run app.py
```

افتحوا الرابط المحلي الذي يظهر في الطرفية. تُحفظ الرسائل في `messages.db` على الجهاز الذي يشغّل التطبيق.

## النشر كرابط عام

يمكن ربط المستودع العام بخدمة Streamlit Community Cloud واختيار `app.py` كنقطة تشغيل. رابط التطبيق العام لا يحتاج إلى تسجيل دخول للزائرات.

لوحة المعلمة تبقى محمية: أضيفوا `TEACHER_PASSWORD` في أسرار إعدادات التطبيق، ولا تضعوا كلمة المرور في GitHub. إذا لم تضبط المعلمة السر، تبقى لوحة المراجعة مقفلة.

تُحفظ الرسائل حاليًا في ملف SQLite على جهاز تشغيل التطبيق. استضافة Streamlit Community Cloud لا تضمن بقاء الملفات المحلية؛ لذلك يلزم ربط قاعدة بيانات مُدارة إذا كان المطلوب حفظ الرسائل باستمرار. لا تنشروا ملف قاعدة البيانات أو كلمة المرور في المستودع.

## الخصوصية

النموذج لا يطلب أسماء أو أرقامًا أو بيانات اتصال. تظل الرسالة مخفية إلى أن توافق عليها المعلمة. ينبغي تنبيه الطالبات إلى عدم كتابة بيانات شخصية داخل نص الرسالة.
